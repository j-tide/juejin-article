# Agent 系统工程：第一季配套实验

这一套 Python 3.10+ 标准库项目为第 01—10 篇提供可复现机制实验。第 01 篇的修订实现保存在 `lab/acceptance.py`，后续模块按章节逐步增加，最终由 `integration.py` 串联。

**这是本地教学实验项目，没有接入在线模型、真实检索或外部交付服务。** 文中的规划与协作结论明确区分受控脚本、数学推导和未运行的模型实验。它不是已经通过生产验收的完整 Agent 产品。

## 运行

在本目录运行任一章节：

```bash
python3 run.py 02 --output results/02.json
python3 run.py 03 --output results/03.json
python3 run.py 04 --output results/04.json
python3 run.py 05 --output results/05.json
python3 run.py 06 --output results/06.json
python3 run.py 07 --output results/07.json
python3 run.py 08 --output results/08.json
python3 run.py 09 --output results/09.json
python3 run.py 10 --output results/10.json
python3 integration.py
```

不需要安装依赖，不读取用户凭证，不调用模型或发送网络请求。各章用临时目录保存数据库，实验结束后自动删除。第 02 篇会启动自己的子进程并让它在提交前后退出，父进程检查退出码和数据库恢复结果；不会终止其他进程。

## 模块与演进

| 章节 | 新增模块 | 实际验证 |
| --- | --- | --- |
| 01 | `acceptance.py` | 结构验收、快照绑定、异常引用与新任务目录边界 |
| 02 | `runtime.py` | 子进程崩溃前后的本地事务一致性、旧版本写入拒绝 |
| 03 | `delivery.py` | 两个独立数据库中的交付意图、丢回执、查询、去重 |
| 04 | `authorization.py` | 可信测试授权与动作、任务、目标、产物和期限匹配 |
| 05 | `context.py` | 保留控制字段、明确字符预算、证据快照版本检查 |
| 06 | `memory.py` | 候选、批准、范围、期限、冲突和依赖撤回 |
| 07 | `planning.py` | 固定失败环境中的控制触发与预算边界 |
| 08 | `collaboration.py` | 证据根重叠检查、冲突路由、假设下的概率计算 |
| 09 | `evaluation.py` | 教学计数上的 pass@k 与 pass^k 组合估计 |
| 10 | `episode_10.py` | 第一篇原始解析缺陷的冻结输入回放与回归检查 |

每个 `episode_NN.py` 是该章的实验入口与断言。`results/` 保存各章实验输出。可按上面的命令重新生成结果，实验入口中的断言会检查对应机制。

本季文章目录分别提供 `code.zip`，包含截至对应章节可用的累计模块、运行说明与必要实验数据。只有第 10 版包含完整集成入口；旧快照可独立运行，不依赖后续文章目录。快照编号表示教学项目演进阶段，不代表框架或商业产品版本。

## 已知边界

- 第 01 篇修订版有完整的 10 组场景与 9 个单元测试，保存在该篇独立目录中。
- SQLite 实验只验证同机进程退出，不模拟断电或损坏。没有分布式租约和契约自动迁移。
- 交付服务用一条数据库记录模拟业务效果，没有真实邮件或文档平台；未实现自动扫描未完成意图或并发客户端完整重试调度。
- 授权由宿主测试代码创建，不是模型输出。没有实现沙箱、授权服务身份验证和在线撤销。
- 上下文预算按字符而非 token 计算；任务依赖和来源根部分由测试数据给定。
- 记忆批准由可信测试代码执行，不能自动判断主张真假；范围字段不替代服务端身份认证。
- 规划实验有已知备用来源；协作输出为固定角色记录，没有执行多个模型。
- 第 09 篇数字完全是教学数据，不是当前项目的任务成功率。
- 第 10 篇 trace 是简化 JSON，没有集成 OpenTelemetry SDK。

## 完整集成的验收范围

`integration.py` 将任务、上下文、记忆、控制策略、来源登记、验收、授权和模拟交付连在一起。它检查丢回执后只存在一条交付记录、接收的产物内容保持一致，以及证据撤回后有效性变为待重验。历史交付状态不被抹去。

真实模型实验设计写在对应文章中，尚未执行；需要在有明确模型、预算和真实任务集的环境中另行验证。
