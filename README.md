# AI Agent 学习笔记

学习 AI Agent 的一些记录。边读源码边做小实验，把遇到的问题和自己的理解整理下来。

文章按专栏和篇号整理，配套代码与图片放在对应目录。

## 代码和配图

打开文章文件夹就能读正文。示例代码放在各专栏的 `code/`，运行步骤见里面的 README；单篇的附件和实验结果也能从专栏目录找到。

图片放在 `assets/`。有可编辑源文件的图，另外放在专栏的 `diagrams/`；其中的 HTML 下载后可以直接用浏览器打开。

## 勘误

推导、引用或者代码有问题，欢迎提 Issue，最好带上文章位置和复现过程。补充资料和不同的实现思路也欢迎讨论。

[内容与代码的使用](COPYRIGHT.md)

错字、链接和表述可以直接提 PR；修改实现或推导时，请带上代码版本与复现过程。文章路径沿用 `专栏序号-专栏名称/篇号｜文章标题/`，新增文章时同步更新首页和专栏目录。

引用优先使用原论文、官方文档和固定提交的源码。实验说明环境与输入，区分脚本化测试和真实模型结果；改动代码后按对应运行说明执行相关测试。
